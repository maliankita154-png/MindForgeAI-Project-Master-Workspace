# Contributing to a MindForgeAI Industry Project

This repository is owned by Chatake Innoworks Pvt. Ltd. Students contribute as project team members through their own GitHub identities.

## Required workflow

1. Pull the latest `main` branch.
2. Create `member/STUDENT-ID/short-task-name`.
3. Work inside your member workspace or the specific assigned project folder.
4. Never commit credentials, personal information, restricted data or unexplained generated files.
5. Run the relevant tests and update documentation, evidence and diary records.
6. Push the member branch and open a pull request.
7. Explain what changed, why it changed, how it was tested and which issue/task it completes.
8. Obtain review before merging.

## Codex and AI-agent contributions

Codex may edit, test, commit and push work when it runs inside the student's authenticated local environment. The student remains responsible for every change and must inspect the diff, understand the implementation and verify the tests before opening a pull request.

AI agents must never receive company-owner tokens, shared passwords, production secrets or another person's GitHub credentials.

## Definition of a reviewable pull request

- one clear purpose;
- limited and understandable scope;
- no secrets or private student data;
- tests or reproducible verification;
- linked task or issue;
- updated technical documentation;
- screenshots or evidence when the visible product changes;
- known limitations stated honestly.
