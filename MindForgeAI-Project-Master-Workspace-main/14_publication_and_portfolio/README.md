# Publication and Portfolio Workspace

This folder prepares the approved public representation of the project for the Chatake Innoworks project gallery and future student technology-profile platform.

## Target locations

- Project gallery: `https://projects.chatakeinnoworks.com/<project-slug>`
- Future verified profiles: `https://tech.chatakeinnoworks.com/u/<profile-slug>`
- Canonical source: the assigned repository under `https://github.com/Chatake-Innoworks/`

## Required public package

- `PROJECT_SHOWCASE_PROFILE.md` completed and approved;
- project logo/cover and accessible screenshots;
- concise problem, user and impact statement;
- architecture and workflow diagram;
- approved team attribution and contribution notes;
- technology stack and deployment details;
- repository, demonstration, report and video links;
- evidence-backed results and limitations;
- licence, dataset rights and acknowledgements;
- privacy and secret scan completed.

## Publication gates

1. Technical review: project runs and evidence supports claims.
2. Safety review: no credentials, private data or restricted material.
3. Rights review: code, datasets, assets and names can be published.
4. Communication review: description is accurate and understandable.
5. Release review: URLs, screenshots, fallback demo and ownership are correct.

Only the approved release is published. Draft research, raw personal data, private diaries and internal feedback never belong on the public project page.
