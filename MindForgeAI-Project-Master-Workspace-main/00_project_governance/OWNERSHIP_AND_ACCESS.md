# Ownership and Access Policy

## Canonical ownership

- Repository owner: `Chatake-Innoworks` GitHub organization.
- Administrative control: authorized Chatake Innoworks administrators only.
- Project coordination: Maintain access where operationally required.
- Active project students: Write access to their assigned repository only.
- Reviewers and observers: Read or Triage access according to responsibility.

Students must never receive organization-owner access or company credentials. Access is removed or reduced after the project handover while authorship and contribution history remain visible.

## Protected main branch

`main` represents the reviewed, reproducible and demonstrable project state. It should require a pull request, review and relevant status checks. Force pushes and deletion are prohibited.

## Intellectual property and public release

Public availability is not the same as unrestricted ownership. Before release, the Program Office must approve:

- software licence and copyright notice;
- dataset source, licence and redistribution permission;
- student-name/photo/profile consent;
- removal of secrets, personal data and restricted company information;
- publication claims, metrics and limitations;
- third-party assets and acknowledgements.

Proprietary components remain in a private company repository. The public showcase may contain a safe demonstration, documentation and approved source subset.

## Student identity and attribution

Students contribute through their own GitHub accounts so commits and pull requests preserve authorship. Team pages must distinguish team membership, specific contributions and company/project ownership without exaggerating individual claims.
